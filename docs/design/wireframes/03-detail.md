# 화면: 공고 상세

**목적:** 매칭된 공고 1건의 상세 정보와 매칭 근거를 보여주고, 사용자가 파싱 결과를 나라장터 원문과 반드시 대조할 수 있게 한다.
**진입 경로:** 이메일 알림의 상세 링크, 공고 피드(`02-feed.md`) 카드 클릭.

## 레이아웃

위에서 아래 순서로 배치한다.

1. **헤더** — 공고명, 나라장터 공고번호와 개정 차수, 발주기관, 마감일시와 남은 기간.
2. **나라장터 원문 링크 버튼 — 필수 요소.** 헤더 바로 아래, 화면에서 스크롤 없이 닿는 위치(above the fold)에 고정 배치한다. 이 버튼이 필수인 이유: 수집·파싱 과정에서 원문과 다른 값이 저장될 수 있고, 사용자는 이 값을 근거로 입찰 참여 여부를 판단하므로 반드시 원문으로 대조할 수 있는 통로가 있어야 한다(`01-RESEARCH.md` §Security Domain > Known Threat Patterns 세 번째 행 "공고 원문 파싱 결과와 원문 불일치로 인한 사용자 손해 — 원문 보기 링크 필수 배치"; 위협 등록부 `T-01-15`).
3. **핵심 요약 표** — 물품분류코드와 분류명, 참가가능지역, 예산금액, 계약방법, 공고 게시일.
4. **참가자격 원문 발췌 영역** — 파싱된 참가자격 텍스트를 그대로 보여준다. 이 서비스는 여기에 해석·판정(예: "참가 가능")을 덧붙이지 않는다 — 자격 판정 기능은 §범위 경계 참고.
5. **매칭 근거 영역** — 이 공고가 왜 이 업체에 매칭됐는지: 일치한 분류코드 prefix와 그 자릿수(예: "43 대분류 일치"), 지역 일치 여부.
6. **하단 액션** — 원문에서 입찰 참여하기(외부 링크, 나라장터로 이동), 이 공고 저장/관심 표시, 이 업종 알림 조정하기(`04-notification-settings.md`로 이동).
7. **고지 문구 영역** — "조달메이트는 정보 제공·보조 도구이며, 입찰 참여 전 반드시 나라장터 원문을 확인하시기 바랍니다." 고정 배치(`PROJECT.md` Legal 제약).
8. **범위 경계** — 참가 자격 판정 결과 배지는 `Phase 4`의 몫이라 이번 화면에 포함하지 않고, 낙찰률·경쟁강도 통계 영역은 `Phase 5`의 몫이다(`D-10`).

## 상호작용

- 나라장터 원문 링크 클릭 → 새 탭에서 나라장터 원문 공고 페이지로 이동한다.
- 참가자격 영역의 "더 보기" 클릭 → 발췌 텍스트가 펼쳐지며 전체 원문 발췌를 보여준다(접힘 상태가 기본값).
- 매칭 근거 영역의 "자세히" 클릭 → 일치한 prefix와 지역 조건을 항목별로 펼쳐 보여준다.
- "이 공고 저장" 클릭 → 버튼 상태가 "저장됨"으로 바뀌고 저장 목록에서 나중에 다시 찾을 수 있다는 토스트를 표시한다.
- "이 업종 알림 조정하기" 클릭 → `04-notification-settings.md`로 이동하며, 이 공고의 업종 맥락을 쿼리 파라미터로 전달한다(`00-user-journey.md` §화면 간 데이터 인계 계약).
- "피드로 돌아가기" 클릭 → `02-feed.md`로 이동하며, 이전에 적용했던 필터·정렬 상태를 보존한다 — 사용자가 상세를 확인하고 돌아왔을 때 목록을 처음부터 다시 좁히지 않게 하기 위함이다.

## 데이터 소스

`bid_announcements`를 공고 식별자(`announcement_id`)로 읽고, `matches`에서 이 업체의 매칭 근거를 읽는다. 원문 API 응답 전체(`raw_payload`)는 화면에 통째로 노출하지 않고, 정규화된 필드(핵심 요약 표·참가자격 발췌)만 표시한다 — 파싱 오류가 있는 필드까지 원문 그대로 신뢰하게 만들지 않기 위함이다. 알림에서 진입한 경우(`match_id`가 URL에 포함)와 피드에서 진입한 경우(`announcement_id`만 URL에 포함, `matches`는 세션의 `company_id`로 재조회)는 넘어오는 값이 다르다 — `00-user-journey.md` §화면 간 데이터 인계 계약과 일치해야 한다.

## 엣지 케이스

- **이미 마감된 공고** — 헤더에 "마감됨" 배지를 표시하고, 원문 링크·매칭 근거는 그대로 유지한다(참고용 열람은 가능).
- **개정되어 최신 차수가 따로 있는 공고** — "이 공고는 개정되었습니다 → 최신 공고 보기" 안내 배너를 헤더 아래 표시하고, 클릭 시 최신 차수의 상세로 이동한다(`ING-03`).
- **파싱 실패로 필드가 비어 있는 공고** — 비어 있는 필드는 "정보 없음"으로 표시하고 값을 추측해 채우지 않는다. 이 경우 나라장터 원문 링크 버튼을 시각적으로 강조(예: 강조색 테두리)해 원문 확인을 유도한다.
- **취소·삭제된 공고** — 상세 진입 시 "이 공고는 취소되었거나 더 이상 조회할 수 없습니다" 안내와 피드로 돌아가는 링크만 표시하고, 나머지 상세 영역은 렌더링하지 않는다.
- **다른 업체의 매칭 식별자로 접근 시도** — URL의 `match_id`가 로그인한 업체 소유가 아니면 조회를 거부하고 403 안내 화면을 표시한다. 자기 업체 범위 밖의 매칭 근거·프로필 정보는 어떤 경로로도 노출하지 않는다(`T-01-16`).
