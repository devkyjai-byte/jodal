# 화면: 공고 피드 (매칭된 공고 목록)

**목적:** 로그인한 업체에게 매칭된 공고 목록을 보여주고, 키워드·업종·지역·마감일로 좁혀볼 수 있게 한다.
**진입 경로:** 온보딩 완료 직후 자동 이동(`01-onboarding.md` §상호작용), 로그인 후 기본 진입 화면, 이메일 알림 본문의 "전체 목록 보기" 링크.

## 레이아웃

위에서 아래 순서로 배치한다.

1. **상단 필터 바** — **키워드·업종·지역·마감일** 네 축(`ING-04`). 키워드는 자유 텍스트 검색창, 업종은 온보딩에서 등록한 prefix 기반 다중 선택 드롭다운(등록하지 않은 prefix도 임시로 추가 선택 가능), 지역은 시/도 다중 선택, 마감일은 "이번 주 / 이번 달 / 직접 지정" 범위 선택.
2. **정렬 선택** — 적합도순(기본값) / 마감임박순 / 최신 등록순.
3. **공고 카드 리스트** — 카드 1장에 표시되는 항목:
   - 공고명
   - 발주기관
   - 마감일시와 남은 기간(예: "D-3")
   - 예산금액
   - 적합도 표시 — 5단계 정성 등급("매우 적합"~"참고용")으로 표시하고 백분율·점수 숫자는 노출하지 않는다. **근거:** 소수점 점수나 "낙찰 가능성 87%" 류의 표현은 확정적 예측으로 읽힐 위험이 있다(`PROJECT.md` Legal 제약 — 정보 제공·보조 도구 포지셔닝, 낙찰 보장 표현 금지). 정성 등급은 "이 공고가 당신의 프로필과 얼마나 겹치는지"를 안내하는 참고 정보일 뿐임을 카드 하단에 한 줄로 명시한다.
   - **매칭 근거 한 줄** — 예: "정보통신(43) 업종 등록과 일치" 처럼 업체가 등록한 어느 분류코드 prefix와 일치했는지 표시해, 사용자가 왜 이 공고를 받았는지 바로 알 수 있게 한다.
4. **더 보기 방식** — 무한 스크롤을 선택한다. **근거:** 공고 피드는 탐색형 목록이라 사용자가 페이지 번호를 기억할 필요가 없고, 모바일(Capacitor 래핑) 환경에서 스크롤이 페이지네이션 탭보다 자연스럽다. 단, 스크린리더·URL 공유를 위해 필터·정렬 상태는 쿼리스트링에 반영한다.

## 상호작용

- 키워드 입력 후 검색 아이콘 클릭 또는 Enter → 목록이 키워드 일치 공고로 필터링된다.
- 업종 필터에서 항목 선택/해제 → 목록이 즉시 재조회된다(디바운스 적용).
- 지역 필터에서 시/도 선택 → 목록이 해당 지역 참가가능 공고로 좁혀진다.
- 마감일 필터에서 "이번 주"를 선택 → 목록이 7일 이내 마감 공고로 좁혀진다.
- 정렬 드롭다운에서 "마감임박순" 선택 → 목록이 마감일 오름차순으로 재정렬된다.
- 공고 카드를 클릭 → `03-detail.md`로 이동하며 공고 식별자(`announcement_id`)를 URL 파라미터로 전달한다(`00-user-journey.md` §화면 간 데이터 인계 계약과 일치).
- "필터 초기화" 버튼 클릭 → 네 축 필터가 모두 해제되고 정렬은 적합도순으로 되돌아간다.

## 데이터 소스

`matches`와 `bid_announcements`를 업체 범위로 조인해 읽는다 — `matches.company_id`가 로그인한 업체의 `company_id`와 일치하는 행만 조회하며, 모든 조회가 로그인한 업체 범위로 한정된다(다른 업체의 매칭 결과는 어떤 경로로도 노출되지 않는다). 키워드 검색은 PostgreSQL의 단순 `LIKE`가 아니라 검색엔진(`Meilisearch` 또는 `OpenSearch`)을 경유할 수 있다 — 어느 쪽을 쓸지 최종 선택은 Phase 2로 위임한다.

## 엣지 케이스

- **프로필이 미완성이라 매칭이 아예 없는 상태** — 업종을 하나도 등록하지 않은 경우(온보딩을 건너뛴 예외 경로가 생기면) 카드 리스트 대신 "업종을 등록하면 맞춤 공고를 받아볼 수 있어요" 안내와 온보딩 스텝 2로 바로 가는 링크를 표시한다.
- **매칭 0건** — 프로필은 등록했지만 현재 조건에 맞는 공고가 없는 경우. "선택하신 업종 범위가 좁을 수 있어요" 안내와 함께 업종 선택을 넓히도록 유도하는 문구, 그리고 온보딩(업종 스텝)으로 돌아가는 링크를 제공한다(`00-user-journey.md` §여정이 끊기는 지점).
- **로딩 상태** — 최초 진입 또는 필터 변경 직후 카드 자리에 스켈레톤 placeholder를 표시한다.
- **네트워크 오류·오프라인** — PWA 특성상 오프라인 진입이 가능하다. 마지막으로 캐시된 목록이 있으면 "오프라인 상태 — 마지막 업데이트 기준" 배지와 함께 캐시된 목록을 보여주고, 캐시가 없으면 재시도 버튼을 제공한다.
- **마감이 지난 공고의 표시 방침** — 기본 정렬·필터에서는 자동 제외하되, 사용자가 "마감된 공고 포함" 토글을 켜면 카드에 "마감됨" 배지를 달아 목록 하단에 표시한다(참고용 — 재입찰 여부 확인 목적).
