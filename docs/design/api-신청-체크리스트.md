# 나라장터 Open API 4종 활용신청 체크리스트

> 이 문서는 설계·운영 참고 문서이며 실행 코드가 아니다.

## 왜 이것부터인가

나라장터 Open API 4종은 개발계정 기준 자동승인이면 신청 후 20~30분 내 승인되지만, 서비스별로 자동승인이 아니라 심의승인 대상일 수 있고 심의는 1~2일 정도 걸릴 수 있다는 것이 확인됐다(RESEARCH.md Pitfall 2, Open Question 2). 4개 서비스 중 어느 것이 심의승인인지는 신청 화면에서 직접 확인하기 전까지 알 수 없으므로, 승인 대기 시간을 Phase 1 전체 일정의 임계 경로로 취급해야 한다. 그래서 이 체크리스트의 목적은 사용자가 지금 바로 4건을 동시에 제출하게 하는 것이다 — 승인을 기다리는 동안 나머지 설계 산출물(플랜 02~04: 스키마·매핑·와이어프레임)이 병렬로 진행되므로, 신청을 먼저 끝내는 것이 전체 Phase 1을 가장 빨리 끝내는 방법이다.

## 신청 절차

아래 5단계를 위 4개 서비스 각각에 대해 반복한다(4번 반복).

1. **data.go.kr 회원가입/로그인** — 이미 계정이 있으면 로그인만. 개인회원/기업회원 어느 쪽이든 신청 가능하나, 이후 사업 운영을 고려하면 기업회원으로 전환하는 것을 권장(운영계정 전환 시 유리할 수 있음 — 확정 아님, 실행 시 재확인).
2. **대상 서비스 페이지 접속 후 "활용신청" 버튼 클릭** — 위 표의 URL로 이동해 페이지 중앙 또는 우측 상단의 "활용신청" 버튼을 누른다.
3. **시스템 유형·활용목적·상세기능(오퍼레이션) 입력**
   - 시스템 유형: "일반" 선택(별도 안내가 없는 한).
   - 활용목적 예시 문구(그대로 복사해 사용 가능): "중소기업이 나라장터 입찰공고를 업체 프로필(업종·지역·실적·인증)과 매칭해 놓치지 않도록 안내하는 정보 제공·보조 서비스 개발에 활용합니다." — "낙찰 보장", "입찰 대행" 같은 표현은 PROJECT.md 법적 제약상 절대 쓰지 않는다.
   - 상세기능(오퍼레이션): 화면에 나열된 오퍼레이션을 우선 전체 선택한다. 실사용 범위가 확정되면 Phase 2 실행 시 필요한 것만 남기도록 조정한다.
4. **승인방식 확인** — 신청 제출 직후 또는 마이페이지 > API활용현황에서 해당 서비스가 자동승인인지 심의승인인지 표시된다. 자동승인이면 개발계정 기준 약 20~30분 내 승인, 심의승인이면 담당 기관 심사(1~2일 보고 사례 있음)를 거친다. 확인한 값을 아래 "신청 상태 추적표"에 기록한다.
5. **승인 후 "일반 인증키 받기"로 서비스키(인증키) 발급** — 마이페이지 > API활용현황에서 승인된 서비스를 열어 인증키를 발급받는다. 기업회원은 프로젝트 서비스키/개인 서비스키 중 선택 가능하다. 발급받은 키는 절대 이 문서나 다른 어떤 문서에도 붙여넣지 말고, 아래 "서비스키 보관 규칙"에 따라 `.env`에만 저장한다.

## 서비스키 보관 규칙

- 키는 `.env` 파일의 `NARAJANGTEO_SERVICE_KEY` 로 보관한다.
- `.env` 는 `.gitignore` 에 포함되어야 한다 — 절대 git에 커밋하지 않는다.
- 이 문서를 포함한 어떤 마크다운 산출물에도 실제 키 값을 붙여넣지 않는다. 예시가 필요하면 반드시 `<REDACTED>` 같은 자리표시자만 쓴다. 예: `NARAJANGTEO_SERVICE_KEY=<REDACTED>`
- 키는 서버 사이드에서만 사용하고, Next.js 클라이언트 번들로는 절대 내보내지 않는다(브라우저에 노출되면 즉시 유출).
- data.go.kr은 Encoding 키와 Decoding 키 두 종류를 함께 발급한다. 실제 호출 시 어느 쪽이 정상 동작하는지는 Phase 2 실행 시 두 키를 각각 테스트해 확인한다.

## 미해결 확인 항목

1. **4개 서비스 각각의 승인방식(자동승인/심의승인)이 무엇인가** (RESEARCH.md Open Question 2) — 누가 언제 확인하는가: 사용자가 신청 시 화면 또는 마이페이지 > API활용현황에서 직접 확인해 위 "신청 상태 추적표"에 기록한다.
2. **개발계정 일 1,000건 한도가 ING-01(일 4~6회 폴링)에 충분한가** (RESEARCH.md Open Question 4) — 누가 언제 확인하는가: Phase 2 실행 시 실제 페이지네이션 응답 구조(페이지당 결과 수, 총 호출 수)를 보고 판단한다. 부족하면 운영계정으로 전환하며, 운영계정은 활용사례 등록 후 최대 10만 건/일까지 상향 가능하다.
