# 서비스명·도메인 확정 체크리스트

> 이 문서는 설계·운영 참고 문서이며 실행 코드가 아니다.

## 서비스명 (확정)

서비스명은 **조달메이트**로 확정한다(D-01). 확정 근거: `PROJECT.md`, `ROADMAP.md`, `REQUIREMENTS.md` 및 GitHub 저장소 설명에 이미 이 이름이 전면적으로 사용되고 있어, 지금 변경하면 다수 문서를 다시 써야 하는 비용이 크다.

영문 표기는 **Jodalmate**로 병기한다. 이 영문 표기는 다음 지점에서 공통 기준값으로 쓰인다:
- 도메인 후보명(아래 "도메인 방침" 참조)
- 앱스토어/플레이스토어 등록명
- PWA manifest의 `name` / `short_name` 필드(Phase 2 — Next.js PWA 최초 빌드 시점)

이 항목은 이미 확정된 기존 결정을 기록하는 것이며, 추가 사용자 액션이 필요하지 않다.

## 도메인 방침

D-02에 따라 `.co.kr` 형식을 1순위로 한다 — 국내 B2B·조달 업체를 대상으로 하는 서비스 특성상 `.co.kr`이 `.com`이나 일반 `.kr`보다 신뢰도 면에서 유리하다는 판단이다.

| 순위 | 도메인 후보 | 비고 |
|------|-------------|------|
| 1순위 | `jodalmate.co.kr` | 서비스명(Jodalmate) + `.co.kr` 조합, 국내 B2B 신뢰도 최우선 |
| 2순위 | `jodalmate.kr` | `.co.kr` 등록 불가 시 대체 — `.co.kr`보다 신뢰도는 낮지만 짧고 동일 어근 유지 |
| 3순위 | `jodal-mate.co.kr` | 하이픈 포함 변형 — `jodalmate.co.kr`이 이미 선점됐을 경우의 근접 대체 |
| 4순위 | `jodalmate.com` | 국제형 대체 — 향후 해외 확장 여지는 있으나 국내 B2B 신뢰도 우선순위(D-02)와는 맞지 않아 최후순위 |
